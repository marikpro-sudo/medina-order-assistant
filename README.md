# Medina — AI order assistant for a pharmaceutical distributor's B2B portal

Medina is a chat widget for a B2B pharma ordering portal. It turns messy orders — free text in
Russian or Kazakh with typos, photos of handwritten lists, Excel files with arbitrary columns —
into a validated file in the portal's strict order-upload format, with in-stock analogs for
missing items, pack-multiple corrections and warnings before upload. A human always confirms.

> Work in progress. Full documentation, metrics and demo video will be added by the submission.

## Built during the hackathon

All code in this repository was written during the Meta Global AI Developer Hackathon,
starting 2026-10-28. The first commit (`96cd0a4`) is the starting point. All data is synthetic.
